# 术语规范

## 规范名称

当前参考原型统一称为 **v0版**。以下位置必须使用这个名称：

- 产品界面、教程、架构图和演示文案；
- 研究报告、阶段报告和后续执行计划；
- 代码注释、测试说明、提交说明和发布说明；
- Notion/语雀传输源及以后新增的同步内容。

上游仓库机器名 `agent_atore_demo`、固定 commit、URL、Notion 页面 ID、语雀 slug 等技术
标识保持原样，不把展示名称变化误做成仓库或远端对象迁移。

## 审计边界

以下材料不改写：

- 已有 Git commit 和 `archive/*` 冻结引用；
- 用户原始请求、automation 输入和会话证据；
- 已冻结的历史同步检查点。

它们保留的是当时事实。当前主线、后续新提交和新生成的可交付内容必须通过术语门禁。

Notion 与私人语雀的本次远端更名由用户手动完成；本阶段不执行远端写入或回读。对应
本地台账只记录用户报告，不升级为实时验证证据。

## 自动门禁

运行：

```bash
PYTHONPATH=src .venv/bin/python -m pytest tests/test_terminology.py
```

测试会扫描当前仓库的活动文本文件和路径；发现废弃称呼时直接失败。历史 Git 对象和仓外
原始输入不属于扫描范围。
