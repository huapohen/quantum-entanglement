# 术语规范

## 规范名称

当前参考原型统一称为 **v0版**。以下位置必须使用这个名称：

- 产品界面、教程、架构图和演示文案；
- 研究报告、阶段报告和后续执行计划；
- 代码注释、测试说明、提交说明和发布说明；
- Notion/语雀传输源及以后新增的同步内容。

该规则同时覆盖旧中文称呼和旧拼音拼写，包括活动文件名、路径与链接。

上游仓库机器名 `agent_atore_demo`、固定 commit、URL、Notion 页面 ID、语雀 slug 等技术
标识保持原样，不把展示名称变化误做成仓库或远端对象迁移。

## 审计边界

以下材料不改写：

- 已有 Git commit 和 `archive/*` 冻结引用；
- 用户原始请求、automation 输入和会话证据；
- 已冻结的历史同步检查点。
- 记录既有远端回读事实的历史同步 manifest。

它们保留的是当时事实。当前主线、后续新提交和新生成的可交付内容必须通过术语门禁。

Notion 与私人语雀的远端更名最初由用户手动完成。2026-08-27 用户随后明确重新授权
Notion 正文同步；29 个页面已完成写入和逐页回读，并登记为实时验证证据。语雀本轮仍未
操作，除非用户以后再次明确授权，不得把 Notion 授权扩展到语雀或其他外部系统。

## 自动门禁

运行：

```bash
PYTHONPATH=src .venv/bin/python -m pytest tests/test_terminology.py
```

测试会扫描当前仓库的活动文本文件和路径；发现废弃中文称呼或旧拼音拼写时直接失败。
历史 Git 对象、冻结同步检查点、历史远端回读 manifest 和仓外原始输入不属于扫描范围。
